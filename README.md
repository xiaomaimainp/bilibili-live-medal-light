# bilibili-live-medal-light
Tampermonkey 油猴脚本，B站网页直播间一键点赞点亮粉丝勋章，支持 blanc 极简直播间。

## 功能
- 兼容普通直播间与 `/blanc/` 轻量化直播间页面
- 模拟点击原生点赞按钮，循环30次点赞，用于续粉丝牌
- 页面固定单个小圆按钮，不会重复生成多个按钮
- SPA切换直播间自动重建按钮

## ⚠️ 风险提示
1. 仅用于已经加入主播粉丝团的账号，没有粉丝团勋章无法点亮
2. 内置点赞间隔 500ms，**不要连续多次点击按钮**，高频操作会触发B站风控限制点赞
3. 本脚本仅调用页面原生点赞逻辑，不会发送礼物、消耗B币/瓜子

## 安装
1. 浏览器安装 Tampermonkey / Violentmonkey 油猴插件
2. 点击脚本链接导入，或者新建脚本粘贴代码保存
3. 打开B站直播间，右上角出现 🔥 圆形小按钮

## 使用
打开B站直播间，点击右上角🔥按钮，自动连续点赞30次。
控制台可以查看点赞进度。

## 注意
- 主播必须**正在开播**，未开播页面没有点赞按钮，脚本会提示找不到按钮
- 粉丝牌点亮状态存在B站服务器延迟，跑完后等待片刻或刷新勋章面板查看
